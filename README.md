# とびら ― ちいさな旅

ドアを開けて少しずつ先へ進む、18〜25分ほどの短い3D体験。
敵も、時間制限も、難しい操作もありません。ただ歩いて、光を集めて、誰かと少し話して、扉を開けます。
道の途中に、一度だけ **すこし こわい夜** があります。

**`index.html` ひとつだけで動きます。** ブラウザで開くだけ（three.js のみ CDN から読み込み）。
画像・3Dモデル・音声ファイルは一切使わず、地形も草木も人も動物も音楽もすべて実行時に生成しています。

## 遊びかた

| 操作 | スマートフォン | PC |
|---|---|---|
| 歩く | 画面左側をドラッグ（バーチャルスティック） | `W A S D` / 方向キー |
| 見まわす | 画面右側をドラッグ | 画面をドラッグ / `Q` `E` |
| 話す | 人に近づく（頭の上に吹き出しが出ます） | 同じ |
| 扉を開ける | 扉に近づくと現れる「ひらく」ボタン | 同ボタン / `Enter` `Space` |
| 音を消す | 右上の ♪ | 同じ |

各章に散らばる「ひかり」を全部集めると、扉の上の玉がすべて灯り、扉が開きます。
光は遠くからでも見える細い光の柱を立てているので、それを目印に歩いてください。
頭の上に ちいさな灯がある人は、まだ話していないことがある人です。

人に近づくと、その人の**頭の上に吹き出し**が出ます。吹き出しは3D空間の位置を画面に投影して
追従し、画面の端では位置を寄せつつ しっぽだけが相手を指し続けます。悪夢の章では黒い吹き出しに
変わります。地の文（詩）はこれまでどおり画面下に出ます。

### 物語の たてすじ

はじまりの草原で、**こども**が「だれかを待っている」と言います。誰を待っていたかはもう忘れた、
それでも待つのは嫌いじゃない、と。旅は最後にこの言葉へ戻ってきます。

**ともしびの まち**は、歩くのをやめた人たちの町です。町の「とびらの ばんにん」が世界の理を教えてくれます
――扉は誰かが作るものではなく、「行きたい」と思った場所にひとりでにできるのだと。
そしてこの町の人は、みんな自分の扉を閉じたのだと。**ひかりを拾うたびに、家の窓が数軒ずつ灯ります。**
全部集める頃には、町じゅうに明かりがともっています。

**わすれられた夢**（悪夢）では、影にまじって一人だけ座っている人がいます。
**むかしの わたし**――ここで歩くのをやめた自分です。「きみは、まだ あるける?」と訊いてきます。
次の章のおばあさんが、その答え合わせをしてくれます。

最後の扉の前には、最初に出会った**ぼうしの ひと**が待っています。
「ぼくは ここで まつことに したよ。つぎの ひとが とおるまで。あの まちの あかりみたいに ね。」
待つことも旅のひとつだった ― 物語はここで円を閉じます。

第四章は暗く、赤く、心音が鳴り、影がゆっくり近づいてきます。
**ただし敵ではありません。触れても何も起きず、ゲームオーバーもありません。**
（章のはじめに「なにも おそっては こない。あるけば いい。」と伝えます。）

## 音楽（すべて Web Audio API によるピアノ音の手続き生成）

1音は「ピアノ倍音の波形オシレータ + わずかにデチューンした正弦波 + ハンマーノイズ」を
時間とともに閉じるローパスと指数減衰エンベロープに通し、手続き生成したインパルス応答の
リバーブへ送っています。楽譜（和音進行・旋律）はコード内のデータで、左手の伴奏型は
和音から自動生成され、ループごとに変奏（オクターブ重ね／オルゴール風／休符）が切り替わります。

| # | 曲名 | 場面 | 調・速さ | 伴奏の型 |
|---|---|---|---|---|
| 1 | とびらのまえで | タイトル画面 | F / 58 | ゆっくりした分散和音 |
| 2 | あさのみち | 第一章 はじまりの草原 | C / 76 | 流れる8分音符 |
| 3 | みずのきおく | 第二章 みずのにわ | Am / 64 | 広い分散和音＋残響のこだま |
| 4 | **まちの あかり** | 第三章 ともしびのまち | G / 84・**3拍子** | なつかしいワルツ |
| 5 | **わすれられた夢** | 第四章 悪夢 | 三全音と半音のクラスター / 50 | しのびよる不規則な低音 |
| 6 | ゆうぐれのとびら | 第五章（クライマックス） | Dm / 74 | 推進する8分＋自動ハモリ |
| 6' | 同上（静かな再演） | 第六章 さいごのかいだん | 強度 0.34 | 薄い編成 |
| 7 | またあおう | エンディング | F / 52 | ささやくような和音 |

悪夢の曲だけ全音符を ±26セント ランダムにずらしてあり、
**調律の狂ったピアノ**として鳴ります。扉を抜けた瞬間に音楽は断ち切られ、
静寂のあと、温かいFの分散和音（あんどの音）が鳴ります。

BGM はすべてループし、場面が変わると数秒かけてクロスフェードします。
第四章では**光を集めるほど演奏が厚くなり**、旋律の重ね・低音の追加・きらめきの密度が増していきます。

効果音もすべてピアノの響きです。

- **扉を開く音**：5種類の長い上昇分散和音（章ごとに変わる／深いリバーブの余韻つき）
- **扉が目覚める音**：全部集めたときの温かいロール和音
- **ひかりを拾う音**：ペンタトニックの階段を1つずつ登る2〜3声のチャイム
- **話しかける音**：人ごとに音域のちがう やわらかな2音
- **窓に灯がともる音**：高音域の2声（家が灯るたび、少しずつ音が上がっていきます）
- **足音／鳥の声／魚のはねる音**：その場の調にあわせた ごく小さな単音
- **悪夢**：低いピアノの心音（近いほど速くなる）、狂ったクラスターのささやき、ぞっとする一撃

## 技術メモ

- three.js r128（CDN 4か所を順に試すフォールバック付き）
- 地形は値ノイズ＋ドーム減衰＋湖のくぼみから生成し、同じ高さ関数を描画・移動・配置・水際の判定に共用
- 木・草花・岩・敷石・影は `InstancedMesh`（描画コール 38〜122、三角形 25k〜40k）
- 家は手続き生成（壁・四角錐の屋根・煙突・扉・窓）。窓は消灯色から点灯色へ補間して灯ります
- 人・動物・影はパーツ組み立ての手続き生成。歩行・呼吸・羽ばたき・尾のゆれをコードで動かしています
- 空・水・扉の光・光柱はカスタムシェーダ、草木の揺れは `onBeforeCompile` で頂点を揺らしています
- 縦画面優先。`safe-area-inset` 対応、フレームレートが落ちた場合は解像度を自動で下げます
