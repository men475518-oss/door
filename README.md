# とびら ― ちいさな旅

ドアを開けて少しずつ先へ進む、8〜15分ほどの短い3Dインタラクティブ体験。
敵も、時間制限も、難しい操作もありません。ただ歩いて、光を集めて、扉を開けます。

**`index.html` ひとつだけで動きます。** ブラウザで開くだけ（three.js のみ CDN から読み込み）。
画像・3Dモデル・音声ファイルは一切使わず、地形も草木も音楽もすべて実行時に生成しています。

## 遊びかた

| 操作 | スマートフォン | PC |
|---|---|---|
| 歩く | 画面左側をドラッグ（バーチャルスティック） | `W A S D` / 方向キー |
| 見まわす | 画面右側をドラッグ | 画面をドラッグ / `Q` `E` |
| 扉を開ける | 扉に近づくと現れる「ひらく」ボタン | 同ボタン / `Enter` `Space` |
| 音を消す | 右上の ♪ | 同じ |

各章に散らばる「ひかり」を全部集めると、扉の上の玉がすべて灯り、扉が開きます。
光は遠くからでも見える細い光の柱を立てているので、それを目印に歩いてください。

## 音楽（すべて Web Audio API によるピアノ音の手続き生成）

1音は「ピアノ倍音の波形オシレータ + わずかにデチューンした正弦波 + ハンマーノイズ」を
時間とともに閉じるローパスと指数減衰エンベロープに通し、手続き生成したインパルス応答の
リバーブへ送っています。楽譜（和音進行・旋律）はコード内のデータで、左手の伴奏型は
和音から自動生成され、ループごとに変奏（オクターブ重ね／オルゴール風／休符）が切り替わります。

| # | 曲名 | 場面 | 調・速さ | 伴奏の型 |
|---|---|---|---|---|
| 1 | とびらのまえで | タイトル画面 | F / 58 | ゆっくりした分散和音 |
| 2 | あさのみち | 第一章 はじまりの草原 | C / 76 | 流れる8分音符 |
| 3 | みずのきおく | 第二章 みずのにわ | Am / 64 | 広い分散和音＋残響のこだま |
| 4 | ゆうぐれのとびら | 第三章 ゆうぐれのおか（クライマックス） | Dm / 74 | 推進する8分＋自動ハモリ |
| 4' | 同上（静かな再演） | 第四章 さいごのかいだん | 強度 0.34 | 薄い編成 |
| 5 | またあおう | エンディング | F / 52 | ささやくような和音 |

BGM はすべてループし、場面が変わると数秒かけてクロスフェードします。
第三章では**光を集めるほど演奏が厚くなり**、旋律の重ね・低音の追加・きらめきの密度が増していきます。

効果音もすべてピアノの響きです。

- **扉を開く音**：5種類の長い上昇分散和音（章ごとに変わる／深いリバーブの余韻つき）
- **扉が目覚める音**：全部集めたときの温かいロール和音
- **ひかりを拾う音**：ペンタトニックの階段を1つずつ登る2〜3声のチャイム
- **足音**：その場の調のごく小さな低音（左右交互）
- **章のはじまり／UI／最後の光**：やわらかな単音と分散和音

## 構成

タイトル → 第一章（ひかり5）→ 第二章（6）→ 第三章（6）→ 第四章（光の道を歩くだけ）
→ エンディング → 「もういちど あるく」

## 技術メモ

- three.js r128（CDN 4か所を順に試すフォールバック付き）
- 地形は値ノイズ＋ドーム減衰＋湖のくぼみから生成し、同じ高さ関数を描画・移動・配置・水際の判定に共用
- 木・草花・岩・影は `InstancedMesh`（描画コール 38〜57、三角形 25k〜38k）
- 空・水・扉の光・光柱はカスタムシェーダ、草木の揺れは `onBeforeCompile` で頂点を揺らしています
- 縦画面優先。`safe-area-inset` 対応、フレームレートが落ちた場合は解像度を自動で下げます
